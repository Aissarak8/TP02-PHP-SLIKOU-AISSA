## Exercice 2

En PHP, les variables sont sensibles à la casse.
Ainsi, `$note` et `$Note` sont deux variables différentes.

### Noms de variables valides
- `$a`
- `$_a`
- `$a_a`
- `$AAA`
- `$a1`

### Noms de variables invalides
- `$a!`
- `$1a`
